# Resurrections
Création d'un fichier "status.js" dans lequel nous avons ajouté les actions suivantes : /
- Récupérer les objets enregistrés /
- Rechercher l'objet concerné /
- Vérifier que l'objet existe /
- Modifier son statut /
- Sauvegarder la modification /

La connexion utilisateur n'est pas nécéssaire à ce stade du développement, mais peut-être intéressante par la suite /
